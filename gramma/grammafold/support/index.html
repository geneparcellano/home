Getting started

  1. Open Grammafold and click Choose Folder to select the directory containing your scattered photos and videos.
  2. Start the scan. Grammafold will recursively search the folder and read metadata from each supported file to determine its date.
  3. Review the preview. Before any files are moved, you’ll see a complete organization plan showing where each file will go.
  4. Confirm and organize. When you’re satisfied with the plan, confirm to move files into the date-based folder structure.
  5. Undo if needed. If something isn’t right, use the undo feature to restore your previous folder layout.

Your files remain on your Mac throughout the entire process. Grammafold does not upload anything to the cloud.

Frequently asked questions

  • Does Grammafold upload my photos?

    No. Grammafold works entirely on your Mac. Your photos, videos, and metadata never leave your computer. There are no cloud uploads, no servers, and no network transmission of your files.

  • Does Grammafold modify my photos?

    No. Grammafold only moves files into organized folders. It does not edit, compress, convert, or alter the contents of your photos or videos in any way.

  • What happens if dates are missing?

    Grammafold reads dates from photo and video metadata (such as EXIF data). If a file has no usable date in its metadata, Grammafold falls back to the file’s creation or modification date on disk. Files with uncertain dates are clearly shown in the preview so you can review them before organizing.

  • What happens if files have the same name?

    Grammafold uses safe collision handling. If a file with the same name already exists in the destination folder, Grammafold will not overwrite it. Instead, it appends a unique suffix to avoid data loss. You can review all collision resolutions in the preview before confirming.

  • What file formats are supported?

    Grammafold supports common photo and video formats including JPEG, HEIC, HEIF, TIFF, PNG, RAF, DNG, CR2, NEF, ARW, MOV, MP4, M4V, AVI, and MKV.
